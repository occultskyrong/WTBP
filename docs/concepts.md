# 概念模型

WTBP 的最小认知单元不是“结论”，而是“带场景约束的决策”。

```text
场景变量 + Practice + Evidence + Reference Implementation
                         ↓
                项目 Decision Record
                         ↓
                    可执行 Skill
                         ↓
                     Eval 与反馈
```

Practice 提供可复用判断，Decision Record 保存一次具体选择，Skill 固化重复流程，Eval 检验这些内容是否真的改善结果。不同模型可以给出不同建议，但必须使用相同的上下文、实践 ID、证据和输出字段。
