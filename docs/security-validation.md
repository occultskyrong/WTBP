# 外部 Skill 与项目安全校验

## 目的

搜索到的 GitHub 项目、外部 Skill 和压缩包都只能先视为不可信候选。WTBP 提供一个默认只读的本地静态校验器，帮助发现隐藏后门、凭据或公私钥窃取、权限滥用、危险下载执行、安装钩子、工作流注入和 Prompt Injection 等高风险信号。

```bash
wtbp "为 Playwright 找可复用的 GitHub Skill"
wtbp security-check /path/to/unpacked-candidate
wtbp security-check /path/to/unpacked-candidate --format json
```

校验器不会自动下载、安装、导入、执行候选代码，不访问外部网络，也不会把匹配到的密钥或 Token 写入报告。`json` 报告包含规则、文件、行号、脱敏证据、阻断状态和静态校验边界，适合留存到候选评估记录中。

## 结果与门禁

| 结果 | 含义 | 采用动作 |
|---|---|---|
| 通过 | 未发现当前规则定义的高风险信号 | 仍需核对来源、版本、许可证、依赖和运行时权限 |
| 需人工复核 | 发现未固定 Action、动态执行或安全校验关闭等信号 | 隔离候选，补充人工审查和依赖漏洞扫描 |
| 阻断 | 发现私钥材料、凭据与网络外传、远程下载后直接执行、提权、危险工作流检出、明显 Prompt Injection，或存在未验证的二进制/压缩包/超限/不可读内容 | 不安装、不执行、不提供凭据；记录证据并拒绝候选 |

退出码为 `0=通过`、`1=阻断`、`2=需人工复核`、`64=参数错误`。安全校验器是采用门禁，不是漏洞不存在证明；未知后门、运行时行为、依赖漏洞和服务端风险仍需要隔离环境、固定版本、依赖数据库和运行时最小权限验证。

## 校验范围

- 凭据文件、环境变量、私钥材料的读取，以及与网络上传入口的相邻组合。
- `curl|bash` 等下载即执行、动态解释执行、编码/解码后执行、危险提权和系统持久化。
- npm 安装生命周期脚本、Git Hook、Actions 的不可信上下文脚本注入、过宽 Token 权限和未固定到完整提交 SHA 的 Action。
- Skill 文档中的忽略安全规则、索取系统提示词、凭据或私钥的指令。
- 符号链接越出目标目录、二进制和压缩/打包文件等无法由文本规则完整确认的内容。

压缩包默认不递归解压，二进制、压缩包、超限、不可读和符号链接内容默认阻断；先在隔离目录安全展开或完成哈希/签名复核，再重复校验。依赖漏洞应在候选来源固定后显式运行 OSV-Scanner 等依赖扫描，不把依赖扫描结果伪装成本地行为校验结果。

## 采用流程

```text
搜索候选
   ↓
固定公开来源、提交版本并下载到隔离目录
   ↓
wtbp security-check <目录>
   ├─ 阻断：拒绝候选
   ├─ 需复核：人工审查 + 依赖/许可证/运行时权限验证
   └─ 通过：仍需来源、版本和运行时验收
```

这个流程与 [`network-first-capability-governance.md`](network-first-capability-governance.md) 的“先检索、再核验、最后采用”一致；`wtbp` 搜索结果不会因为安全校验器存在而自动变成可执行能力。
