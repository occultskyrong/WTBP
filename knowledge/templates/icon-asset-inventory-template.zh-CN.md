# 图标与视觉资产清单

项目设计契约和整体架构获批后、页面级样式开始前，必须建立这份清单。它把可复用 Icon 资产与页面组合分离，并记录会引发视觉漂移的关联资产。

## 尺寸、风格与状态契约

使用矢量母版，只建立声明终端和实际场景需要的尺寸。默认角色如下：

| 尺寸 | 典型角色 | 必须检查 |
|---|---|---|
| 16 | 紧凑表格/列表或行内操作 | 像素对齐和可辨识的视觉重量 |
| 20 | 标准控件或输入框附属图标 | 光学居中和触达区分离 |
| 24 | 主操作、导航、TabBar 或移动端控件 | 外框/导航对齐和选中状态 |
| 32 | 功能提示或空状态符号 | 视觉重量仍属于同一图标家族 |

`48px+` 属于插画/空状态作品，不属于常规 Icon 系统。不得默认导出所有尺寸：只记录实际使用的变体；当缩放会改变描边、细节或光学平衡时，必须独立设计经过校正的变体。

## 图标资产门禁

1. **来源与归属（`IA-01`）**：检查真实项目/Figma 库，记录来源、归属、许可证/权限和过期或不可访问证据。
2. **语义抽离（`IA-02`）**：把批准页面/状态使用的每个 Icon 抽取为语义 ID，不得有重复语义或页面级替代品。
3. **尺寸与家族（`IA-03`）**：按真实角色定义需要的 16/20/24/32 变体、母版网格、线/填充、光学对齐和终端例外。
4. **状态与 Token 映射（`IA-04`）**：映射颜色 Token 和需要的状态变体；不得硬编码颜色或混用未经确认的图标库。
5. **缺失 Icon 设计（`IA-05`）**：每个缺失 Icon 在页面使用前都有独立可复用组件、家族比对、复核决策和来源/节点映射。
6. **实现映射（`IA-06`）**：每个 Figma 与产品实例映射到同一 Icon ID、组件、尺寸、状态和精确资产/导出物。
7. **渲染保真（`IA-07`）**：在声明终端外框中检查所需尺寸/状态的像素对齐、光学平衡、对比度、触达区分离、裁剪和回退行为。

每项必须记录 `pass`、`blocked` 或明确批准的例外。来源缺失、图标家族未批准或页面 Icon 未映射时，阻断页面级样式、实现交接和验收。
