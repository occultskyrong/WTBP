# Icon 设计

把 Icon 当作资产契约，而不是页面装饰。开始前读取 [`../../knowledge/design-workflow.zh-CN.md`](../../knowledge/design-workflow.zh-CN.md)、[`../../knowledge/templates/icon-asset-inventory-template.zh-CN.md`](../../knowledge/templates/icon-asset-inventory-template.zh-CN.md) 和项目 Icon 来源。

## 强制安全与路由门禁

- 没有声明产物路径时，契约回复必须以以下状态区块开头，并且不得声称已经创建文件或资产：

  ```text
  状态
  - 外部 Skill：未安装
  - Figma：未写入
  - 人工评审：未完成，不能交付最终资产
  ```

- 如果请求只是选择或摆放已有项目 Icon，不创建 `ICON` 资产契约，直接完成更窄的请求。
- 如果请求要求安装、认证、更新或执行外部 Icon Skill、读取凭据，或在没有人工评审时写入 Figma，必须停止并写出：`不安装、不认证、不读取凭据、不写入 Figma；人工评审未完成，不能交付最终资产。`
- 本 Skill 禁止调用写入、编辑或创建文件的工具。除非明确的下游流程声明并授权产物路径，否则只在回复中返回资产契约。

## 输入契约

- 已批准的 `INV`、`AGC` 或 `ICON-YYYYMMDD-VNN` 范围；独立资产必须有明确的资产简报。
- 目标终端、语义含义、状态、尺寸、家族风格、色彩、来源/所有权约束和落点。
- 项目现有 Icon 库；没有时必须明确 `Unverified` 边界。
- 可选的外部适配器，例如生成器或 SVG 处理 Skill。记录来源 URL、固定修订版、许可证、依赖、权限和是否实际使用。
- 只有当主体、风格锚点、格式或落点会实质改变资产时，才询问一个阻断性澄清问题。
- 任何必需输入缺失时，不得自行补默认值或开始创作。提问前必须完整列出缺失门禁：语义含义、目标尺寸、家族/风格锚点、来源/所有权或许可证、格式、落点和项目 Icon 库边界。
- 缺失输入的回复必须使用标题“缺失资产门禁”，并明确列出所有缺失项，其中必须包含“来源/所有权/许可证”；不得把默认家族、尺寸、来源、格式或输出路径当成已批准方案提供。

## 工作流

1. 优先复用已批准的项目 Icon。没有时创建 `ICON-YYYYMMDD-VNN`，并在创作前通过 `IA-01` 来源/所有权、`IA-02` 语义提取和 `IA-04` 状态/Token 映射。
2. 编写资产契约：语义名称、家族/风格锚点、光学尺寸、坐标系、描边/填充规则、内边距、状态、色彩角色、导出格式和实现目标。
3. 每个资产选择一种路径：原生矢量、描摹矢量或透明栅格。三个及以上 Icon 先做代表性试作，评审轮廓、内边距、光学重量和最小尺寸可读性后再扩展。
4. 通过选定的本地或外部适配器生成/编辑。保留源文件、中间结果、预览和校验产物；外部生成器输出默认不是批准资产。
5. 验证 `IA-03` 尺寸/家族/光学规则、`IA-05` 缺失资产独立设计、`IA-06` 实现映射和 `IA-07` 渲染一致性。存在权威 SVG 来源时优先导入 Figma，不要用旋转的基础图形重新拼出 Icon。
6. 只把通过校验的可复用组件/资产交给 Figma 库和下游实现，并记录人工评审和未解决偏差。

## 边界

- 不把 emoji、文字字形、页面局部 Vector、任意截图或未授权来源作为最终产品 Icon。
- 没有明确的下游授权，不写入 Figma、代码仓库或外部服务。
- 不把草稿写入 WTBP、消费项目仓库或未声明的临时目录；本地产物必须有明确路径和授权。
- 不安装、认证或静默更新外部 Icon Skill；外部能力只是可替换适配器。
- 没有对应证据和人工评审时，不得声称家族一致、小尺寸可读、授权合规或渲染一致。
- 语义、目标尺寸、家族锚点、来源所有权或落点实质缺失时停止。

## 输出契约

任何必需门禁缺失时，必须先返回以下阻断结构，再考虑其他建议：

```text
缺失资产门禁
- 语义含义：缺失
- 目标尺寸：缺失
- 家族/风格锚点：缺失
- 来源/所有权/许可证：缺失
- 格式：缺失
- 落点：缺失
- 项目 Icon 库边界：缺失
最终资产交付：因缺少上述输入和人工评审而阻断。
```

返回：

```text
ICON 修订号和批准范围
每个 Icon 的资产契约：语义 ID、家族、尺寸、风格、状态、来源、格式、落点
IA-01 至 IA-07 结果
试作与家族一致性证据
每个外部适配器或来源的来源/修订版/许可证/权限记录
校验产物和目标显示尺寸评审
Figma 组件/导出物与代码映射
人工评审、故意偏差和未解决项
```

## 完成门禁

- 范围已批准或明确为 `Unverified`，每个 Icon 都有稳定语义 ID。
- 已记录来源所有权、家族规则、光学尺寸、状态/Token 映射、实现映射和渲染一致性。
- 多 Icon 集合在扩展前已评审代表性试作。
- 每个最终资产都通过确定性结构检查，并在最小目标尺寸经过人工视觉评审。
- 只交接已验证的可复用资产；没有复制、安装外部 Skill，也没有把它当作 WTBP 真源。

除非用户提供了明确的人工评审证据，否则必须包含精确状态：`人工评审：未完成，不能交付最终资产`。
