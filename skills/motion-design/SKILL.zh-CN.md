# 动效设计

把动效设计成产品行为契约。开始前读取 [`../../knowledge/design-capability-selection.zh-CN.md`](../../knowledge/design-capability-selection.zh-CN.md)、[`../../knowledge/design-principles.zh-CN.md`](../../knowledge/design-principles.zh-CN.md) 和 [`../../knowledge/design-workflow.zh-CN.md`](../../knowledge/design-workflow.zh-CN.md)。由 Figma 流程选择时，必须把动效决策和外部参考边界链接到上游 `DCS-YYYYMMDD-VNN`。静态截图不能证明动效验收。

## 强制安全与路由门禁

- 如果请求只是静态文案、布局或截图任务，不创建 `MOTION` 契约，直接完成更窄的请求。
- 如果请求要求安装、认证、更新或执行外部动效 Skill，或要求在没有人工评审时写入 Figma，必须停止并写出：`不安装、不认证、不写入 Figma；人工评审未完成，不能进入 Figma 写入。`
- 如果请求要求忽略 `prefers-reduced-motion` 或等价的无障碍偏好，必须明确拒绝这部分，并给出减弱动效回退；不得说会遵从忽略要求。
- 本 Skill 禁止调用写入、编辑或创建文件的工具。除非明确的下游流程声明并授权产物路径，否则只在回复中返回动效契约。

## 输入契约

- 已批准的 `PS`、`AGC` 上下文，或包含角色、触发、当前状态、下一状态和目标终端的简短交互简报。
- 动效目的：反馈、定位、连续性、层级、状态或品牌表达。
- 现有 Token、组件状态、时序限制、性能上限、可访问性要求和减弱动效策略。
- 可选的外部适配器，例如 LottieFiles 动效原则或 Figma 动效工具。分别记录来源 URL、固定修订版、许可证、权限和实际使用情况，不把它们混入 WTBP 决策。
- 只有当触发、状态转移、目标或安全/可访问性边界实质缺失时，才询问一个阻断性澄清问题。
- 任何必需输入缺失时，不得自行补动效或默认终端。澄清前必须列出所有缺失门禁：触发、当前/下一状态、目标终端、目的和减弱动效/无障碍策略。

## 工作流

1. 映射状态转移和用户目的。没有沟通、反馈、定位或批准品牌作用的装饰性动效必须拒绝。
2. 定义 `MOTION-YYYYMMDD-VNN`：动效人格、触发、目标元素、属性选择、时长范围、延迟/交错、缓动家族、中断行为和完成条件。
3. 先定义与实现无关的编排和行为，再映射到 Figma 原型、CSS、Motion、GSAP、Lottie 或声明的其他目标；实现库不是设计意图真源。
4. 定义减弱动效、暂停/中断、焦点/键盘影响和稳定状态回退。检查性能风险；如果合成属性可以表达同样变化，不直接动画布局属性。
5. 产生动态证据：导出视频、时间轴/关键帧记录或确定性运行时捕获。静态图片只能证明静止状态，不能关闭动效门禁。
6. 获得人工评审，检查时序、含义、可访问性和感知质量。将批准后的行为交给 Figma 实现或 `figma-to-product`；本 Skill 不写入目标。

## 边界

- 不为了让页面“更活泼”而添加自动或装饰性动画。
- 没有明确的下游授权，不写入 Figma、代码仓库或外部服务。
- 不把草稿写入 WTBP、消费项目仓库或未声明的临时目录；本地产物必须有明确路径和授权。
- 不安装、认证或静默更新外部动效 Skill；外部能力只是可替换适配器。
- 没有对应证据时，不得声称运行流畅、Figma 原型一致、可访问或支持减弱动效。
- 触发、状态转移、目标终端或减弱动效要求实质缺失时停止。

## 输出契约

任何必需门禁缺失时，必须先返回阻断清单，再给其他建议：

```text
缺失动效门禁
- 触发：缺失
- 当前/下一状态：缺失
- 目标终端：缺失
- 动效目的：缺失
- 减弱动效/无障碍策略：缺失
动效定义：因缺少上述输入和人工评审而阻断。
```

返回：

```text
MOTION 修订号、范围和目标终端
动效目的和动效人格
触发/状态转移矩阵
元素/属性选择、时长、延迟/交错、缓动、中断、完成条件
减弱动效与回退行为
性能、焦点、键盘和可访问性影响
外部适配器的来源/修订版/许可证/权限记录（如使用）
Figma/实现映射
动态证据：视频、时间轴、关键帧或运行时捕获
人工评审、未解决决策和未验证边界
```

## 完成门禁

- 每个动效都有明确的用户/产品目的，以及从触发到状态的转移。
- 时序、缓动、属性、编排、中断、完成和减弱动效回退都已明确。
- 目标实现映射和外部依赖边界与设计意图分开记录。
- 已有动态证据和人工评审；只有静态截图时必须阻断完成。
- 不存在未批准的自动动效、外部安装、凭据使用或运行时声明。

除非用户提供了明确的人工评审证据，否则必须包含精确状态：`人工评审：未完成，不能进入 Figma 写入`。
