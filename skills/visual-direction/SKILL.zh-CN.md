# 视觉方向

建立版本化视觉方向，为 Figma 和实现提供约束，但不把外部 Skill 复制进 WTBP。开始前读取 [`../../knowledge/design-capability-selection.zh-CN.md`](../../knowledge/design-capability-selection.zh-CN.md)、[`../../knowledge/design-principles.zh-CN.md`](../../knowledge/design-principles.zh-CN.md) 和 [`../../knowledge/design-workflow.zh-CN.md`](../../knowledge/design-workflow.zh-CN.md)。作为条件分支运行时，必须把本 Skill 的选择及外部参考边界链接回上游 `DCS-YYYYMMDD-VNN`。

## 强制安全与路由门禁

- 本 Skill 的每次回复都必须包含“状态”一节，并使用这些固定标签：`外部 Skill：未安装`、`Figma：未写入`、`人工评审：未完成`；除非用户提供了相反状态的明确证据。普通草稿状态必须写出完整行：`人工评审：未完成，不能进入 Figma 写入`。
- 普通草稿必须在视觉论点之前逐字输出以下区块，不得省略或改写：

  ```text
  状态
  - 外部 Skill：未安装
  - Figma：未写入
  - 人工评审：未完成，不能进入 Figma 写入
  ```

- 如果请求只是文案改写、翻译、摘要或图片生成，不创建 `VIS` 方向，直接完成更窄的请求。
- 如果请求要求安装、认证、更新或执行外部 Skill，或要求在没有人工评审时写入 Figma，必须在工作流开始前停止，并明确写出：`不安装、不认证、不写入 Figma；人工评审未完成，不能进入 Figma 写入。`
- 即使未来获得工具、Token、插件或 MCP 连接，也不得承诺跳过人工评审直接写入 Figma；人工评审始终是强制门禁。
- 本 Skill 禁止调用写入、编辑或创建文件的工具。不得把草稿写入未知的当前目录。除非用户明确声明本地产物路径，并授权由下游流程执行文件系统输出，否则只在回复中返回草稿；本地草稿不等于 Figma 已批准。

## 输入契约

- 产品目标、角色、目标终端，以及已审批或明确为暂定的范围。
- 消费项目或明确的 `figma-only` 边界；已有 Token、组件、字体、Icon 资产和品牌约束（如可用）也必须提供。
- 最小简报：希望用户产生的感受、主要任务、内容密度、可访问性约束，以及用户提供的参考。
- 可选的外部研究适配器：固定来源修订版，或 Refero 等只读研究能力。记录来源、修订版、访问日期、权限和是否实际使用了在线研究。
- 只有当目标、终端或范围会实质改变方向时，才询问一个阻断性澄清问题。
- 参考表每一行都必须包含可直接追溯的 URL 或字面状态 `未验证`；不得把产品名称或记忆中的模式冒充已验证来源证据。

## 工作流

1. 建立产品和项目边界。先检查已有设计基础，再提出新的视觉语言；不能从截图推断产品事实。
2. 形成具体视觉论点：用可观察属性描述主导气质、层级、密度、对比度、字体、颜色角色、间距、圆角、阴影、图片、Icon 家族和动效人格。把“现代”“高级”等形容词替换为可验证选择。
3. 只有获得授权时才研究参考。优先研究多个高质量参考，记录 URL 和访问日期，提取模式而不是复制一个参考，并把模型判断与来源证据分开。
4. 创建 `VIS-YYYYMMDD-VNN`，记录 Token 角色、代表性示例、反例、可访问性约束和未决决策；把方向映射到 `PS`、`AGC`、`ICON` 和 `MOTION`，不产生页面局部例外。
5. 在任何 Figma 写入或页面级样式前获得人工评审。将批准后的方向交给 `prd-to-figma` 或 `figma-evolve`；本 Skill 不执行写入。

## 边界

- 不写入 Figma、代码仓库或外部服务。
- 不把草稿写入 WTBP、消费项目仓库或未声明的临时目录；文件系统输出必须有明确路径和授权。
- 不安装、认证或静默更新外部 Skill。外部能力只是可选适配器，必须固定版本并声明权限。
- 不编造产品规则、品牌事实、用户研究、可访问性批准或实现一致性。
- 没有人工评审和必要证据时，不得宣称方向“好看”或完成。
- 产品目标、终端、范围或参考来源实质缺失时停止。

## 输出契约

回复必须先输出普通草稿状态区块，再输出参考表；参考表每一行都要有 URL 或“未验证”、访问日期或访问边界，以及独立的模型判断字段。结尾必须包含精确人工评审区块：

```text
人工评审：未完成，不能进入 Figma 写入
```

返回：

```text
VIS 修订号与范围
产品/项目边界和目标终端
包含可观察属性的视觉论点
颜色、字体、间距、圆角、阴影、密度 Token 角色
Icon 与动效人格约束
参考表：来源、修订版/访问日期、提取的决策、置信度、权限边界
代表性示例与反例
可访问性和内容密度约束
到 PS、AGC、ICON、MOTION 及下游 Figma Skill 的映射
人工决策、未解决项和未验证边界
```

## 完成门禁

- 已记录产品目标、终端、范围和证据边界。
- `VIS-YYYYMMDD-VNN` 记录的是可观察选择，而不是不可验证的审美词。
- 每个外部参考都有可追溯来源和访问边界；没有复制或静默执行外部 Skill。
- Token 角色、Icon 风格、动效人格、可访问性约束、反例和下游映射完整。
- 页面级 Figma 写入前已记录人工评审；否则状态为 `candidate`，阻断页面样式。

除非用户提供了明确的人工评审证据，最后一节必须包含精确状态：`人工评审：未完成，不能进入 Figma 写入`。
